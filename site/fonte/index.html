Feito para quem atende o dia inteiro

  • Uma aba para cada cliente

    Cada conexão vira uma aba com a cor do contato. Arraste para mudar a ordem. O botão do meio do mouse encerra a conexão.

  • Seus contatos do AnyDesk ao lado

    A lista vem do seu catálogo do AnyDesk. Dois cliques conectam. Se o cliente já está aberto, o NaView só troca de aba.

  • O teclado vai para o cliente

    Com uma sessão na tela, o que você digita vai direto para o computador do cliente. F9 mostra os contatos, Ctrl+F abre a busca.

  • Leve durante o atendimento

    Desenhos e animações aparecem só na tela inicial. Com uma sessão aberta, nada fica pesando no computador.

Cada atendimento conta

A cada 10 atendimentos de 3 minutos ou mais, você ganha um baú. Dentro dele vêm temas, pets, acessórios, molduras para os contatos e sons de conexão.

São 31 cartas em cinco raridades. O ritmo é lento de propósito: completar a coleção leva meses.

E tem um pet. Ele nasce de um ovo, come, brinca, cresce e dorme quando o app está fechado.

Baú de demonstração, com as mesmas chances do app. No NaView, as cartas vão para a sua coleção.

Instale em três passos

Baixar o NaView {{VERSAO}}

Pacote {{ARQUIVO}}, {{TAMANHO}}. Para Linux com o AnyDesk instalado.

Conferir se o arquivo chegou inteiro

Rode o comando abaixo na pasta do download. O resultado deve ser igual a este código:

{{SHA256}}
sha256sum {{ARQUIVO}}

  1. Instale o que o NaView precisa

    No Ubuntu e derivados, abra o terminal e rode:

    sudo apt install python3-gi gir1.2-gtk-3.0 gir1.2-webkit2-4.1 gir1.2-gstreamer-1.0 gstreamer1.0-plugins-good gir1.2-notify-0.7

  2. Extraia o pacote na sua pasta pessoal

    tar -xzf ~/Downloads/{{ARQUIVO}} -C ~

    Isso cria a pasta ~/naview.

  3. Crie o atalho no menu

    ~/naview/instalar.sh

    Pronto: procure por NaView no menu de aplicativos. Se faltar alguma biblioteca, o script avisa qual instalar.

Baixar o NaView para Windows

Instalador NaView-instalador.exe. Para Windows 10 e 11 com o AnyDesk instalado.

Conferir se o arquivo chegou inteiro

No PowerShell, na pasta do download, rode o comando abaixo. O resultado deve ser igual a este código:

Get-FileHash NaView-instalador.exe

O instalador para Windows ainda não está disponível aqui. Volte em breve.

  1. Baixe e abra o instalador

    Abra o NaView-instalador.exe da pasta Downloads. O AnyDesk precisa estar instalado.

  2. Libere o aviso do Windows

    Se aparecer O Windows protegeu o computador, clique em Mais informações e depois em Executar assim mesmo. O aviso aparece porque o NaView ainda não tem assinatura digital.

  3. Siga o instalador

    Não pede senha de administrador. No fim, o NaView abre sozinho e fica no menu Iniciar.
